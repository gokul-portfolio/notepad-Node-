A full-stack Notes & Tasks Management Web Application built using the MERN stack.

This project allows users to securely register and log in using JWT authentication, manage personal notes and tasks efficiently, and upload files when required.

The frontend is developed using React (Vite) with a modern UI, while the backend is powered by Node.js, Express, and MongoDB for scalable data handling.

Key features include user authentication, CRUD operations for notes and tasks, protected routes, and responsive design.

features:
User Authentication (JWT-based login/signup)
Secure password hashing using bcrypt
Create, Read, Update, Delete (CRUD) for Notes & Tasks
RESTful API with Express.js
MongoDB database integration using Mongoose
File upload support using Multer
Responsive UI built with React + Bootstrap
API integration using Axios
User-friendly alerts with Toast & SweetAlert


Frontend:

React (Vite)
React Router
Bootstrap & React-Bootstrap
Axios

Backend:

Node.js
Express.js
MongoDB (Mongoose)
JWT Authentication
Bcrypt for password hashing
